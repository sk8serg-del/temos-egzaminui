# Temos egzaminui — подготовка к экзамену по литовскому (A2)

Пользователь — Сергей, общаемся по-русски, коротко и по шагам.

## Что это
Одна веб-страничка `index.html` для заучивания устных тем к экзамену по госязыку
Литвы (I категория, A2). Выбираешь тему → она читается по фразам: сверху литовский
текст с подсветкой слов, снизу русский перевод. Слушает в машине через Bluetooth,
управление кнопками на руле (Media Session API).

## Файлы
- `index.html` — вся страничка (HTML + CSS + JS в одном файле).
  - Тексты тем: массив `BUILTIN` в начале `<script>`. Каждая фраза — отдельная строка
    `["литовский", "русский"],`. Этот формат читает `lt_audio.py`, не ломать его.
  - Правки пользователя на самой страничке хранятся в localStorage браузера
    (ключи `lt-temos-edits-v1`, `lt-temos-custom-v1`), экспорт — кнопка «⇄ Перенести правки».
- Редактор: пользователь пишет русский текст, литовский переводится сам целыми фразами
    (неофициальный Google Translate `translate.googleapis.com/translate_a/single?client=gtx`, CORS открыт, ключ не нужен).
    Неизменённые фразы и ручные правки литовского не перезаписываются (`ruMap`).
- `lt_audio.py` — озвучка живым нейроголосом Microsoft (`lt-LT-OnaNeural`, пакет `edge-tts`).
  Пишет `audio/<md5-хеш-текста>.mp3` и `audio/timings.json`
  (`{ключ: {text, w: [[секунда, слово], ...]}}`). Страничка ищет запись по точному тексту фразы;
  если записи нет — говорит браузерным голосом (Web Speech API).
- Русский перевод тоже озвучивается (`ru-RU-DmitryNeural`, в timings.json поле `"lang":"ru"`) и звучит
  после литовской фразы; переключатель «🔊 Русский после фразы» (localStorage `lt-temos-say-ru`).
- `edits.json` (необязательно) — вставленный текст из «⇄ Перенести правки»;
  скрипт озвучит и эти фразы.

## Частые задачи
- Озвучить всё: `python lt_audio.py` (только новые фразы; одну тему: `python lt_audio.py 1`).
- Поправить текст темы → правка в `BUILTIN` в index.html → `python lt_audio.py`.
- Проверить локально: `python -m http.server 8000` и открыть http://localhost:8000
  (через file:// аудио и timings.json не загрузятся).
- Чтобы пользоваться с телефона, папку нужно выложить на хостинг (например GitHub Pages:
  index.html + папка audio).

## Python и деплой
- Python запускать через `py` (команды `python` на машине нет).
- Git: `.git` вынесен в `D:/git-dirs/LTKALBA`; remote = github.com/sk8serg-del/temos-egzaminui,
  сайт GitHub Pages: https://sk8serg-del.github.io/temos-egzaminui/ (деплой = commit + push).
- `.github/workflows/voice.yml`: на каждый push в main запускает `lt_audio.py`, коммитит новые mp3
  и публикует Pages (источник Pages = GitHub Actions). После сохранения правок страничка сама (autoVoice)
  пишет `edits.json` в репозиторий через GitHub API (fine-grained токен пользователя в localStorage
  `lt-temos-gh-token`) и ждёт, пока появятся mp3; состояние — строка `#vstat` под заголовком (клик = ввести токен / повторить). Если в браузере своих правок нет — страничка берёт `edits.json` с сайта.

## Правила
- Литовский — уровень A2: простые предложения, грамматически правильные. Перевод — естественный русский.
- Не выдумывать факты о пользователе без спроса; плейсхолдеры (семья, друг Андрюс) он правит сам.
